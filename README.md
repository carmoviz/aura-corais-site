# AURA Corais — site de apresentação

Landing page estática (HTML + CSS + JS) do lançamento **AURA Corais**, lofts no Corais do Arraial, Arraial d'Ajuda – BA.
Realização: VRV Incorporadora. Produção: CarmoViz.

- Hospedagem: Vercel (deploy automático a cada push na branch `main`).
- Este repositório contém **só os arquivos publicados**. A fonte (conteúdo em `site.json`, template e scripts de montagem)
  fica na pasta do empreendimento: `Kit Comercial\site\` e `Kit Comercial\fonte\site-template\`.
- Para atualizar: editar `site.json`, dar dois cliques em `PUBLICAR SITE.bat` (monta o site, copia para cá, faz commit e push).

Imagens meramente ilustrativas. Empreendimento sujeito a registro de incorporação.
